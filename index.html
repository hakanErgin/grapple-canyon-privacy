Grapple Canyon privacy policy

Last updated: September 11, 2026

Scope

This policy describes the current Grapple Canyon Android player build, identified by package com.grapplecanyon.game. It applies to the game as shipped in the closed-test candidate. If the app later adds a network service, account, advertising, analytics, purchases, or another data flow, this policy will be reviewed and updated before that build is distributed.

Data kept locally by the app

The game keeps a small amount of player state in local device storage so the same installation can remember the player's choices and progress:

  • Sound preference: on or off (gc.sound.v1).
  • Theme preference: Auto, Day, or Night (gc.theme.v1).
  • Catalogue progression and unlocked tracks (gc.progress.v2).
  • A best time for each track (gc.best.v2.<track-id>).
  • The recent run ghost samples for each track (gc.ghost.v2.<track-id>).
  • The best-run ghost samples used for the best-time comparison (gc.ghostbest.v2.<track-id>).
  • The Full Run best time (gc.fullrun.v2).

Ghost records are gameplay samples used to draw a replay on the same device; they are not a player profile or an online account. The current player catalogue contains five tracks. The game also keeps an in-memory copy while a session is running; if browser storage is unavailable, a new record is not promised to survive reload.

What the current app does not collect

The current player build has no account or login, advertising, analytics or telemetry, remote logging, purchases, social features, user-generated-content service, or remote runtime asset service. It does not send the local state listed above to a Grapple Canyon server. The Android package has no INTERNET permission and the current project disables cleartext traffic. The app's packaged game assets and player state therefore remain local under the current implementation.

These statements describe the current build and are not a promise about a future version with different functionality.

Feedback email

If a user chooses to contact the project at hakan.ergin@gmail.com, the message and any information the user includes are handled by the user's and the email provider's services under their own terms. The game does not automatically collect or transmit feedback, and a user can choose what to include in an email.

Retention, reset, and deletion

Local state remains on the device until the user changes it, uses the game's reset control, clears the app's data, or uninstalls the app, subject to the device operating system's behavior.

In the player build, Reset progress clears catalogue progression and unlocks, per-track best times, recent and best ghost records, and the Full Run best. It preserves the sound and theme preferences. Clearing app data or uninstalling removes the app's local state under the current Android no-backup contract. There is no Grapple Canyon account or server-side profile to delete.

Security and offline posture

The app uses the platform's local storage for the state above and currently does not have an app network service. This limits the app's transmission surface, but no storage method can guarantee absolute security; users should keep their device and operating system protected. The Android project records android:allowBackup="false" and android:usesCleartextTraffic="false"; these are implementation facts to recheck for the exact release candidate, not a promise about every device backup mechanism.

Changes to this policy

If the app's data practices change, the owner will update this policy, change the Last updated date, publish the revised text at the public policy URL, and review the corresponding Play Console Data safety answers before distribution.
