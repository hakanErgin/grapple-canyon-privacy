Grapple Canyon privacy policy

Last updated: October 28, 2026

Scope

This policy describes the Android player build being prepared for the next Grapple Canyon release, identified by package com.grapplecanyon.game. There is no web version. The app has no network service: it makes no network requests and sends nothing to a Grapple Canyon server. If the app later adds an account, advertising, analytics, purchases, or another data flow, this policy must be reviewed and updated before that build is distributed.

Data kept locally by the app

The game keeps a small amount of player state in local device storage so the same installation can remember the player's choices and progress:

  • Sound preference: on or off (gc.sound.v1).
  • Theme preference: Auto, Day, or Night (gc.theme.v1).
  • Catalogue progression and unlocked tracks (gc.progress.v4).
  • A best time for each track (gc.best.v2.<track-id>).
  • The most bonus hoops (stars) collected on a finished run of each track (gc.stars.v1.<track-id>).
  • The best time and best-run ghost samples for each section of a track (gc.secbest.v1.<track-id>).
  • The Full Run best time (gc.fullrun.v4).
  • Editor drafts and the custom levels you saved (gc.editor.draft.v2, gc.custom.v1). An Editor draft from an earlier version (gc.editor.draft.v1) is deleted the next time the game starts.

Ghost records are gameplay samples used to draw a replay on the same device; they are not a player profile or an online account. The current player catalogue contains two tracks. The game also keeps an in-memory copy while a session is running; if browser storage is unavailable, a new record is not promised to survive reload.

Sharing a level

A level you made leaves the device only when you share it. Share on a level in My levels opens Android's share sheet, and you choose the app that sends it (for example, a chat or email app). That app then handles the message under its own privacy terms. The shared level code holds the level and its Recordings, including any names you typed into them, such as the level name. The app adds nothing that identifies you or your device. A code someone sends you is added to My levels only when you paste it into Import level. Grapple Canyon has no server that receives, stores or lists shared levels.

What the current app does not collect

The current player build has no account or login, advertising, analytics or telemetry, remote logging, purchases, or remote runtime asset service. It makes no network requests: the local state listed earlier stays on the device, apart from a level you choose to share. The Android package requests no permission, including no INTERNET permission, and the current project disables cleartext traffic.

These statements describe the current build and are not a promise about a future version with different functionality.

Feedback email

If a user chooses to contact the project at hakan.ergin@gmail.com, the message and any information the user includes are handled by the user's and the email provider's services under their own terms. The game does not automatically collect or transmit feedback, and a user can choose what to include in an email.

Retention, reset, and deletion

Local state remains on the device until the user changes it, uses the game's reset control, clears the app's data, or uninstalls the app, subject to the device operating system's behavior.

In the player build, Reset progress clears catalogue progression and unlocks, per-track best times and stars, section best times and ghost records, and the Full Run best. It preserves the sound and theme preferences, Editor drafts, and custom levels. If the device's storage refuses a deletion, the level list says the reset did not finish, and records it could not delete stay on the device until a later reset succeeds or the app's data is cleared. When levels leave the catalogue, the app deletes their best times, stars and section records, the earlier progression records (gc.progress.v2, gc.progress.v3) and the earlier Full Run bests (gc.fullrun.v2, gc.fullrun.v3), the next time it starts. Reset progress deletes those earlier records too. It also deletes the whole-run ghost records of earlier versions (gc.ghost.v2.<track-id>, gc.ghostbest.v2.<track-id>) and custom levels saved in the earlier level format, with their records.

Earlier versions had a Community Levels service for sharing levels online. It has been removed from the app, and the service and the levels published to it have been deleted. The next time it starts, the app deletes the state that feature kept on the device: the random device identifier (gc.device.v1), the cached level lists (gc.community.cache.v1, gc.community.cache.v2), votes (gc.community.votes.v1), hidden levels and creators (gc.community.blocks.v1), published levels and their removal tokens (gc.published.v1), the author name (gc.author.v1), the rules receipt (gc.community.rules.accepted.v1), and the best times, stars, section records and ghosts of Community levels played earlier. Reset progress deletes them too.

Clearing app data or uninstalling removes the app's local state under the current Android no-backup contract. There is no Grapple Canyon account or server-side profile to delete.

Security and offline posture

The app uses the platform's local storage for the state above. It has no network service and works fully offline. No storage method can guarantee absolute security; users should keep their device and operating system protected. The Android project records android:allowBackup="false" and android:usesCleartextTraffic="false"; these are implementation facts to recheck for the exact release candidate, not a promise about every device backup mechanism.

Changes to this policy

If the app's data practices change, the owner will update this policy, change the Last updated date, publish the revised text at the public policy URL, and review the corresponding Play Console Data safety answers before distribution.
